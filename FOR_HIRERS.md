# For hirers (5 steps)

1. Open https://marchikx.github.io/ops-hq-demo/  
2. Press **1. Fail a webhook**.  
3. Read the green/teal **Result:** sentence under the status boxes.  
4. Optionally press 2 and 3 (payment accept, LLM block).  
5. If that matches a pain you have → https://github.com/marchikx/marchikx/issues/new?template=hire.md  

The KPI cards below the buttons are **sample seed data**. The buttons run real library code.
